# [Lv.1] 카페 메뉴 테이블 만들기

- 문제 번호: 직접 만든 문제
- 분류: CREATE TABLE
- 링크: 직접 만든 문제
- 실습 DB: `USE myschool;`
- 검증: myschool에서 직접 실행해 DESC 결과 확인함

## 테이블

카페의 메뉴 정보를 담을 `LAB07_menus` 테이블을 만들려고 합니다. `name`, `price`, `category`, `is_hot`, `released_date`, `description`은 메뉴 이름, 가격(원), 분류, 따뜻한 음료 여부, 출시일, 메뉴 설명을 의미합니다.

| 컬럼 이름 | 자료형 | 제약 조건 |
| --- | --- | --- |
| name | VARCHAR(30) | NOT NULL |
| price | INT | NOT NULL |
| category | VARCHAR(20) | NOT NULL, 기본값 '커피' |
| is_hot | BOOLEAN | NOT NULL, 기본값 1 |
| released_date | DATE | 없음 |
| description | TEXT | 없음 |

## 문제

표의 자료형과 제약 조건대로 `LAB07_menus` 테이블을 만드는 SQL문을 작성해주세요. 각 컬럼에는 뜻을 COMMENT로 붙이고, 문자셋은 utf8mb4, 콜레이션은 utf8mb4_bin으로 지정해주세요.

## 예시

SQL을 실행한 뒤 `DESC LAB07_menus;`를 실행하면 다음과 같이 출력되어야 합니다.

| Field | Type | Null | Key | Default | Extra |
| --- | --- | --- | --- | --- | --- |
| name | varchar(30) | NO |  | NULL |  |
| price | int(11) | NO |  | NULL |  |
| category | varchar(20) | NO |  | 커피 |  |
| is_hot | tinyint(1) | NO |  | 1 |  |
| released_date | date | YES |  | NULL |  |
| description | text | YES |  | NULL |  |

## 정답

```sql
CREATE TABLE LAB07_menus (
    name VARCHAR(30) NOT NULL COMMENT '메뉴 이름',
    price INT NOT NULL COMMENT '가격(원)',
    category VARCHAR(20) NOT NULL DEFAULT '커피' COMMENT '분류',
    is_hot BOOLEAN NOT NULL DEFAULT 1 COMMENT '따뜻한 음료 여부',
    released_date DATE COMMENT '출시일',
    description TEXT COMMENT '메뉴 설명'
) DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin COMMENT='카페 메뉴';
```

## 해설

- 기본값은 자료형 뒤에 `DEFAULT 값`으로 정함
- BOOLEAN으로 만든 컬럼은 DESC에서 `tinyint(1)`로 보임
