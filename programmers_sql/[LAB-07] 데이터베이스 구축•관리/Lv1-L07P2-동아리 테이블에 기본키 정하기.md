# [Lv.1] 동아리 테이블에 기본키 정하기

- 문제 번호: 직접 만든 문제
- 분류: PRIMARY KEY
- 링크: 직접 만든 문제
- 실습 DB: `USE myschool;`
- 검증: myschool에서 직접 실행해 DESC 결과 확인함

## 테이블

학교 동아리 정보를 담을 `LAB07_clubs` 테이블을 만들려고 합니다. `id`, `name`, `room`, `max_members`, `founded_date`는 동아리 번호, 동아리 이름, 동아리방, 최대 인원, 창립일을 의미합니다.

| 컬럼 이름 | 자료형 | 제약 조건 |
| --- | --- | --- |
| id | INT | PRIMARY KEY, AUTO_INCREMENT |
| name | VARCHAR(30) | NOT NULL |
| room | VARCHAR(20) | 없음 |
| max_members | TINYINT | NOT NULL, 기본값 20 |
| founded_date | DATE | 없음 |

## 문제

표의 자료형과 제약 조건대로 `LAB07_clubs` 테이블을 만드는 SQL문을 작성해주세요. 동아리 번호는 동아리를 추가할 때마다 1씩 자동으로 늘어나야 합니다. 각 컬럼에는 뜻을 COMMENT로 붙이고, 문자셋은 utf8mb4, 콜레이션은 utf8mb4_bin으로 지정해주세요.

## 예시

SQL을 실행한 뒤 `DESC LAB07_clubs;`를 실행하면 다음과 같이 출력되어야 합니다.

| Field | Type | Null | Key | Default | Extra |
| --- | --- | --- | --- | --- | --- |
| id | int(11) | NO | PRI | NULL | auto_increment |
| name | varchar(30) | NO |  | NULL |  |
| room | varchar(20) | YES |  | NULL |  |
| max_members | tinyint(4) | NO |  | 20 |  |
| founded_date | date | YES |  | NULL |  |

## 정답

```sql
CREATE TABLE LAB07_clubs (
    id INT AUTO_INCREMENT COMMENT '동아리 번호',
    name VARCHAR(30) NOT NULL COMMENT '동아리 이름',
    room VARCHAR(20) COMMENT '동아리방',
    max_members TINYINT NOT NULL DEFAULT 20 COMMENT '최대 인원',
    founded_date DATE COMMENT '창립일',
    PRIMARY KEY (id)
) DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin COMMENT='동아리';
```

## 해설

- 기본키는 컬럼 뒤에 `PRIMARY KEY`로 쓰거나, 컬럼을 모두 적은 뒤 `PRIMARY KEY (컬럼)`으로 따로 씀
- `AUTO_INCREMENT` 컬럼은 기본키여야 하며, 기본키는 자동으로 NOT NULL이 됨
