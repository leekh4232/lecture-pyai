# [Lv.1] 동아리 회원 테이블을 동아리와 연결하기

- 문제 번호: 직접 만든 문제
- 분류: FOREIGN KEY
- 링크: 직접 만든 문제
- 실습 DB: `USE myschool;`
- 검증: myschool에서 직접 실행해 DESC 결과 확인함

## 테이블

동아리에 가입한 회원 정보를 담을 `LAB07_club_members` 테이블을 만들려고 합니다. `id`, `club_id`, `name`, `role`, `joined_date`는 회원 번호, 소속 동아리, 회원 이름, 역할, 가입일을 의미합니다. `club_id`는 문제 2에서 만든 `LAB07_clubs` 테이블의 `id`를 가리킵니다.

| 컬럼 이름 | 자료형 | 제약 조건 |
| --- | --- | --- |
| id | INT | PRIMARY KEY, AUTO_INCREMENT |
| club_id | INT | NOT NULL, FOREIGN KEY → LAB07_clubs(id) |
| name | VARCHAR(20) | NOT NULL |
| role | ENUM('회장', '총무', '부원') | NOT NULL, 기본값 '부원' |
| joined_date | DATE | NOT NULL |

## 문제

표의 자료형과 제약 조건대로 `LAB07_club_members` 테이블을 만드는 SQL문을 작성해주세요. `club_id`는 `LAB07_clubs` 테이블의 `id`를 참조하는 외래키로 지정해주세요. 각 컬럼에는 뜻을 COMMENT로 붙이고, 문자셋은 utf8mb4, 콜레이션은 utf8mb4_bin으로 지정해주세요.

## 예시

SQL을 실행한 뒤 `DESC LAB07_club_members;`를 실행하면 다음과 같이 출력되어야 합니다.

| Field | Type | Null | Key | Default | Extra |
| --- | --- | --- | --- | --- | --- |
| id | int(11) | NO | PRI | NULL | auto_increment |
| club_id | int(11) | NO | MUL | NULL |  |
| name | varchar(20) | NO |  | NULL |  |
| role | enum('회장','총무','부원') | NO |  | 부원 |  |
| joined_date | date | NO |  | NULL |  |

## 정답

```sql
-- 부모 테이블 LAB07_clubs(문제 2)가 먼저 있어야 함
CREATE TABLE LAB07_club_members (
    id INT AUTO_INCREMENT COMMENT '회원 번호',
    club_id INT NOT NULL COMMENT '소속 동아리',
    name VARCHAR(20) NOT NULL COMMENT '회원 이름',
    role ENUM('회장', '총무', '부원') NOT NULL DEFAULT '부원' COMMENT '역할',
    joined_date DATE NOT NULL COMMENT '가입일',
    PRIMARY KEY (id),
    FOREIGN KEY (club_id) REFERENCES LAB07_clubs(id)
) DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_bin COMMENT='동아리 회원';
```

## 해설

- 외래키는 `FOREIGN KEY (컬럼) REFERENCES 부모테이블(컬럼)`으로 씀
- 참조할 부모 테이블이 없으면 errno 150 에러가 나므로 부모 테이블을 먼저 만듦
- 외래키 컬럼은 DESC의 Key 칸에 `MUL`로 보임
