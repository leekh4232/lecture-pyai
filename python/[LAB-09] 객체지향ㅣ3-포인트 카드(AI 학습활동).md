## #03. 문제 — 포인트 카드

카페에서 손님마다 포인트 카드를 한 장씩 만들어 줍니다. 손님이 결제할 때마다 **결제 금액의 10%** 를 포인트로 적립하고, 모은 포인트는 결제 대신 쓸 수 있습니다. 포인트 카드 한 장을 나타내는 `PointCard` 클래스를 아래 명세대로 완성하세요. 다음 쪽의 테스트 코드를 고치지 않고 실행했을 때 기대 출력과 똑같이 나와야 합니다.

| 구성 | 하는 일 | 돌려주는 값 |
|:--|:--|:--|
| 생성자 `PointCard(name)` | 손님 이름을 저장한다. 포인트는 0, 결제 기록은 빈 리스트로 시작한다 | 없음 |
| `pay(price)` | 결제 금액을 결제 기록에 담고, 결제 금액의 10%를 포인트에 더한다 | 이번에 적립한 포인트 |
| `use(amount)` | 포인트가 amount 이상이면 amount만큼 뺀다. 모자라면 포인트를 그대로 둔다 | 뺐으면 `True`, 아니면 `False` |
| `report()` | 이름 · 결제 횟수 · 결제 합계 · 남은 포인트를 기대 출력 형식대로 한 줄 출력한다 | 없음 |

<Callout kind="tip" title="제한 조건">

- price는 100 이상 1,000,000 이하, amount는 1 이상인 정수입니다.
- 적립 포인트는 결제 금액의 10%에서 1원 미만을 버린 정수입니다.
- 카드마다 포인트와 결제 기록을 따로 가집니다.

</Callout>

쓰는 문법: 클래스 정의 · 생성자 · 멤버변수 · 메서드 · self(LAB-09), 리스트 append · len · for(결제 합계), 조건문과 True / False, // 연산자, format 또는 f-string.
함정은 세 곳이다. ① 결제 기록 리스트를 생성자가 아니라 클래스 본문에 두면 모든 카드가 한 리스트를 함께 쓴다. 교안이 멤버변수를 클래스 본문(hp = None)에 적는 모양이라 학생이 그대로 따라 하기 쉽다. ② 10%를 * 0.1로 계산하면 450.0처럼 실수가 된다. ③ "이상"을 >로 쓰면 포인트와 똑같은 금액을 쓸 수 없다. 테스트 코드는 이 경우를 다루지 않아서 ③은 테스트를 통과한다(2단계 · 4단 확인 ① 실행 참고).

## #04. 기본 코드 · 테스트 코드

<Grid cols="1fr 1fr" align="start">
<div>

<div class="kicker">기본 코드 — pass 자리를 채운다</div>

```python
class PointCard:
    def __init__(self, name):
        pass

    def pay(self, price):
        pass

    def use(self, amount):
        pass

    def report(self):
        pass
```

<p class="small muted">메서드 이름과 매개변수는 바꾸지 않는다. 필요한 멤버변수는 생성자에서 만든다</p>

<div class="kicker">테스트 코드 — 고치지 않는다</div>

```python
ju = PointCard("주영아")
lee = PointCard("이광호")
print(ju.pay(4500))
print(ju.pay(12000))
print(lee.pay(3000))
print(ju.use(1000))
print(lee.use(1000))
ju.report()
lee.report()
```

class PointCard:
    def __init__(self, name):
        self.name = name
        self.point = 0
        self.logs = []

    def pay(self, price):

        saved = price // 10
