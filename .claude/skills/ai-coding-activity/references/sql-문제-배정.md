## LAB-02 데이터 조회하기

2026-11-11에 목록으로 올리고, 문제 파일 19개를 `programmers_sql/[LAB-02] 데이터 조회하기/`로 옮김. 범위는 SELECT · 별칭 · 사칙 연산 · ORDER BY · LIMIT · WHERE(비교 · 논리 연산자) · BETWEEN · IN · LIKE · IS NULL · 집합 연산자(UNION · INTERSECT · EXCEPT)임. 쉬운 순서로 적음.
